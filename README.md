# Duplicate Cleaner — ניקוי כפילויות

https://xrtor.github.io/Uniq-Copy/

כלי קטן ועצמאי לניקוי כפילויות מרשימות טקסט.

הכלי עובד כולו בדפדפן — אין שרת, אין מסד נתונים, ואין העלאה של הרשימה לשום מקום.

## מה הכלי עושה?

- משאיר רשימה ייחודית לפי סדר ההופעה המקורי.
- מציג אילו ערכים הופיעו יותר מפעם אחת.
- מציג אילו ערכים הופיעו פעם אחת בלבד.
- מציג סטטיסטיקה של מספר השורות והכפילויות שהוסרו.
- מאפשר הדבקה והעתקה מהלוח.

## שימוש

1. פתחו את `index.html` בדפדפן, או הפעילו דרך GitHub Pages.
2. הדביקו רשימה — כתובות URL, טקסט, נתיבים או כל ערך אחר, שורה אחת בכל שורה.
3. לחצו על **פצל לייחודיים/כפולים**.

## GitHub Pages

הפרויקט מוכן ל-GitHub Pages ללא build וללא התקנות.
## פרטיות

כל העיבוד נעשה ב-JavaScript מקומית בדפדפן. המידע שהודבק אינו נשלח לשרת.
